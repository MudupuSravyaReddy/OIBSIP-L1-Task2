# Personal Portfolio

## 📌 Project Overview
A fully responsive, modern personal portfolio website showcasing my skills, projects, and professional background. Built with HTML5 and CSS3, this portfolio serves as my digital résumé – featuring a profile/hero section, about me, skills grid, project cards, and a contact section with a functional form.

## 🛠️ Tech Stack
- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, custom properties, responsive design
- **Font Awesome** – Icons for social links and visual elements
- **Google Fonts** – Inter typeface for clean, modern typography

## ✅ Features Implemented
- [x] Profile/hero section with name, role title, and professional photo
- [x] About Me section with background and interests (3 paragraphs)
- [x] Skills section – visual grid of technical skills with icons
- [x] Projects section – 4 project cards with title, description, and GitHub link placeholders
- [x] Contact section – name, email, phone, location, and LinkedIn/GitHub icons
- [x] Smooth scroll navigation between sections
- [x] Consistent branding – dark theme with purple accent colour scheme
- [x] Fully responsive – works on desktop, tablet, and mobile
- [x] Interactive contact form with validation and success message
- [x] Social media links (GitHub, LinkedIn, Twitter, YouTube)
